# Komainu basics

This document is generated from a template: names between double braces are replaced by what is defined in Rust, and the result is checked before it is written.

## Variables

Variables (symbols) are defined in Rust together with their LaTeX notation, and used by name:

```math
{{ velocity }}
```

They work inline as well: the density is ${{ density }}$, and the time is ${{ time }}$.
The notation is defined only once, so changing it in Rust updates every occurrence.

## Expressions defined in Rust

An expression can be built in Rust, given a name, and used in the same way:

```math
{{ acceleration }}
```

This is useful when an expression is generated by a loop or a function.

## Expressions written in the template

Names can be combined with `+`, `-`, `*`, `/`, `^` and `=` directly in the template:

```math
{{ density * velocity + pressure }}
```

The usual precedence applies. Parentheses you write are kept as written, and no others are added unless the meaning needs them:

```math
{{ pressure - (density + time) * velocity }}
```

Division becomes a fraction, `^` a power, and numbers can be used:

```math
{{ pressure / density = 0.5 * velocity^2 }}
```

Names defined in Rust can be mixed freely:

```math
{{ momentum + pressure = acceleration }}
```

White space does not matter, and an expression may span several lines:

```math
{{ density * velocity
   + pressure
   = 0 }}
```

## Operators

Operators are registered in Rust, together with the number of arguments they take, and called like functions.
Their arguments are expressions as well:

```math
{{ density * partial(velocity, time) }}, \qquad {{ sqrt(pressure / density) }}
```

```math
{{ partial(density * velocity, time) = 0 }}
```

Sums are written with `sum_over` (what is summed over) or `sum_between` (with the range); the summand comes last:

```math
{{ sum_over(index, weight) }}, \qquad {{ sum_between(index, 0, count - 1, weight * velocity) }}
```

Subscripts and superscripts are given separately from the base, so that the notation of the base is defined once.
`sub` is a subscript, and `sup` is a superscript, which is a label such as a step and not a power; both take any expression:

```math
{{ sub(position, i) }}, \qquad {{ sub(position, j + 1) }}, \qquad {{ sup(sub(position, i), n + 1) }}
```

Several indices are separated by commas with `list`, which is written without parentheses inside an index (and in the arguments of a function):

```math
{{ sub(position, list(i, j)) }}, \qquad {{ sub(position, list(i + 1 / 2, j - 1)) }}
```

`angle` puts angle brackets around its argument, which gives an inner product together with `list`:

```math
{{ angle(list(sub(position, i), sub(position, j))) }}
```

A derivative of a single-variable function can be written with a prime or with an order in parentheses, by combining a superscript with a symbol or with parentheses:

```math
{{ prime(pressure) }}, \qquad {{ nth_derivative(pressure, n) }}, \qquad {{ nth_derivative(sub(position, i), n - 1) }}
```

The value of an expression between two bounds, as written after an integration, is `evaluated_between`:

```math
{{ evaluated_between(pressure^2 / 2, -1, 1) }}
```

## Functions

A function is a symbol applied to arguments, which are any expressions; a function of one argument and of two arguments are registered separately:

```math
{{ step(pressure - 1) }}, \qquad {{ f(sup(position, n + 1), time) }}
```

The application is written without parentheses as a base of a power; add them yourself when you want them: `(step(pressure))^2`.

```math
{{ (step(pressure))^2 * f(velocity, time) }}
```

## Plain LaTeX

Anything else is left untouched, including double braces without a space after them: $\epsilon_{{ijk}} {{ velocity }}_{{n}}$.
